# Пример запроса 1С: Номенклатура, реализованная контрагентам-поставщикам

## Краткое название

**«Продажи поставщикам»** — поиск номенклатуры, которую продавали контрагентам, одновременно являющимся поставщиками организации.

## Описание

Запрос находит товары, по которым есть **и закупка (поступление), и продажа (реализация)** одному и тому же контрагенту. То есть контрагент выступает одновременно в роли поставщика и покупателя.

## Код запроса

```sql
ВЫБРАТЬ РАЗЛИЧНЫЕ
    ПоступлениеТоваров.Контрагент
ПОМЕСТИТЬ Поставщики
ИЗ
    Документ.ПоступлениеТоваров КАК ПоступлениеТоваров
;

////////////////////////////////////////////////////////////////////////////////
ВЫБРАТЬ РАЗЛИЧНЫЕ
    РеализацияТоваровТовары.Номенклатура,
    РеализацияТоваровТовары.Ссылка.Контрагент
ИЗ
    Документ.РеализацияТоваров.Товары КАК РеализацияТоваровТовары
ГДЕ
    РеализацияТоваровТовары.Ссылка.Контрагент В
            (ВЫБРАТЬ
                Поставщики.Контрагент
            ИЗ
                Поставщики КАК Поставщики)
```

## Как это работает

### Шаг 1. Список поставщиков

Выбираются уникальные контрагенты из документов **«ПоступлениеТоваров»** и помещаются во временную таблицу `Поставщики`.

```sql
ВЫБРАТЬ РАЗЛИЧНЫЕ
    ПоступлениеТоваров.Контрагент
ПОМЕСТИТЬ Поставщики
ИЗ
    Документ.ПоступлениеТоваров КАК ПоступлениеТоваров
```

### Шаг 2. Основная выборка

Из табличной части **«Товары»** документов **«РеализацияТоваров»** выбираются уникальные пары «Номенклатура — Контрагент», но только по тем контрагентам, которые есть во временной таблице `Поставщики`.

```sql
ВЫБРАТЬ РАЗЛИЧНЫЕ
    РеализацияТоваровТовары.Номенклатура,
    РеализацияТоваровТовары.Ссылка.Контрагент
ИЗ
    Документ.РеализацияТоваров.Товары КАК РеализацияТоваровТовары
ГДЕ
    РеализацияТоваровТовары.Ссылка.Контрагент В
            (ВЫБРАТЬ
                Поставщики.Контрагент
            ИЗ
                Поставщики КАК Поставщики)
```

## Схема работы

| Этап | Действие | Источник | Результат |
|:----:|----------|----------|-----------|
| 1 | Выбор уникальных контрагентов | `Документ.ПоступлениеТоваров` | Временная таблица `Поставщики` |
| 2 | Выбор пар «Номенклатура — Контрагент» | `Документ.РеализацияТоваров.Товары` | Уникальные пары |
| 3 | Фильтрация по подзапросу | Условие `В (...)` | Только контрагенты-поставщики |

## Ключевые конструкции

| Конструкция | Назначение |
|-------------|-----------|
| `РАЗЛИЧНЫЕ` | Убирает дублирование строк |
| `ПОМЕСТИТЬ` | Создаёт временную таблицу |
| `В (...)` | Подзапрос для фильтрации |
| `Ссылка.Контрагент` | Обращение к реквизиту шапки документа через табличную часть |

## Применение

- Анализ взаиморасчётов с контрагентами-партнёрами.
- Поиск товаров с полным циклом «закупка → продажа».
- Подготовка отчётов по совместному обороту.
- Проверка полноты данных по контрагентам.
